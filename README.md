# Ron AI — General Purpose AI Chatbot

## Slice 1: Landing Page
Modern, premium landing page designed for Ron AI with pure HTML5, CSS3, and Vanilla JavaScript.

### Features
- **Visual Faithfulness**: Carefully recreated from reference design (colors, soft 3D cloud atmosphere, glass cards, typography).
- **Mascot & Floating Feature Chips**: Custom friendly Ron mascot with 4 floating AI capability chips ("Ask anything", "Write & create", "Analyze data", "Solve problems").
- **Hero Section**: Premium badge, custom typography gradient, high-converting CTA, and trust indicators.
- **Lower Feature Grid**: 4 equal-height glass cards with custom colored icon containers and smooth hover lift animations.
- **Theme Toggle**: Light mode (reference primary) and dark mode toggle support.
- **Fully Responsive**: Optimized for Desktop, Laptop, Tablet, and Mobile screens.
- **Lightweight & Clean**: Zero heavy frameworks or runtime dependencies.
